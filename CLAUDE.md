# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a tiny practice repository for learning the GitHub pull request workflow (see README.md). It intentionally contains no application code, build system, tests, or tooling — the "task" here is the PR process itself (clone, branch, small change, open a PR), not software development.

## Working in this repo

- There is no build, lint, or test command — nothing has been configured, and none should be assumed.
- Changes should stay small and safe, consistent with the repo's stated purpose of practicing the PR workflow.
